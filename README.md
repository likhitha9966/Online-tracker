# Online Task & Productivity Tracker – Flask Web Application

## Overview
A web application built with Flask (Python) to manage tasks and track productivity effectively.

## Features
- User authentication (Login & Registration)
- Add, update, delete tasks
- Mark tasks as completed
- Track daily productivity
- Simple and responsive UI

## Tech Stack
- Backend: Python, Flask
- Frontend: HTML, CSS, Bootstrap
- Other: Jinja2 Templates

## Setup Instructions

# 1. Clone the repository
git clone https://github.com/likhitha9966/Productivity-Tracker.git

# 2. Navigate to project folder
cd Productivity-Tracker

# 3. Create a virtual environment
python -m venv venv

# 4. Activate the virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# 5. Install dependencies
pip install -r requirements.txt

# 6. Run the application
python run.py
